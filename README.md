# Telegram Bot Private Assistant Geralt

The Telegram bot offers a variety of useful features for personal use to make your life easier and more convenient.

## Features

### 1. **Text Translation**  
Translate text between 6 languages, using integration with a translation service API.

### 2. **Password Generator**  
Generate strong passwords of customizable length and complexity to secure your accounts.

### 3. **Anonymous Email**  
Create temporary email addresses to protect your privacy when registering on websites.

### 4. **Weather Forecast**  
Get current weather updates and forecasts for any city in the world.

### 5. **Reminder**  
Set reminders so you don’t forget important tasks.

### 6. **Game: Hangman**  
Have fun guessing words in the classic Hangman game.

### 7. **URL Shortener**  
Shorten long URLs for easier sharing and use.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/Varckin/Assistant-Geralt-V2.0.git
    ```
2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3. Create a `res/config.json` file and add your Telegram Bot Token:
    ```json
    BOT_TOKEN="sdfsdfh312jkg"
    ```
4. Start the bot:
    ```bash
    python main.py
    ```

## How to Use

1. Find the bot in Telegram by its username.  
2. Start a chat and type `/start` to get a list of available commands.

## Command Examples

- `/translate [text]` — Translate text.  
- `/password [length]` — Generate a password of the specified length.  
- `/anonimmail` — Generate a temporary email address.  
- `/weather [city]` — Get the weather forecast for the specified city.  
- `/reminder [text]` — Create a reminder.  
- `/gallows` — Start the Hangman game.  
- `/shortlink [link]` — Shorten a URL.
